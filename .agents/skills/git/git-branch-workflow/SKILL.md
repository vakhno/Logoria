# Git Branch Workflow

## Branch

After human approval, create a branch:

`<type>/<issue-number>`

Allowed types:

- `feature`
- `story`
- `bugfix`
- `update`

Examples:

- `feature/55`
- `story/72`
- `bugfix/88`
- `update/2`

Do not work on `main` or `master`.
