# Git Backlog Issue Workflow

## Backlog Issues

Create many small draft issue candidates.

Each candidate must include only:

- Title.
- Description.

Do not add type, labels, acceptance checks, edge cases, dependencies, implementation details, or GitHub issue links.

Do not publish to GitHub Issues.

Stop for human review.
